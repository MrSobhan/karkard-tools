# ابزارهای کارکرد (JavaScript / JSX)

مینی‌سایت Next.js (App Router) با Tailwind v4، بدون TypeScript و بدون بک‌اند.

## اجرا
```bash
npm install
npm test
npm run lint
npm run build
npm run dev
```

## نکات
- قوانین کاری: `src/lib/work-rules.js` — منطق: `src/lib/calc.js` — تست‌ها: `src/lib/__tests__/calc.test.js`
- فونت Vazirmatn: فایل `Vazirmatn-Variable.woff2` را در `public/fonts/` بگذارید.
